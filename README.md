# 🎮 Video Game Sales Insight Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze video game sales data across different games, platforms, genres, regions, and years.

## 🎯 Objectives

- Analyze total global video game sales
- Compare sales across different regions
- Identify top-selling games
- Analyze sales by genre
- Understand sales trends over the years
- Explore platform-wise sales performance

## 🛠️ Tools Used

- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Features

- Total Global Sales
- Global Sales Trend by Year
- Regional Sales Distribution
- Sales by Genre
- Top 5 Games by Global Sales
- Platform Filter

## 🔍 Key Insights

The dashboard provides an interactive overview of video game sales and helps identify trends and high-performing games, genres, platforms, and regions.
